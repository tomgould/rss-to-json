# Security policy

## Supported versions

Security fixes go into the latest 2.x release. Version 1.x is no longer supported.

## Reporting a vulnerability

Please report vulnerabilities privately, not in a public issue. Use the "Report a vulnerability" button on the repository's Security tab: https://github.com/tomgould/rss-to-json/security/advisories/new

Include the version, a description of the problem and, if you can, steps to reproduce it. I will reply as soon as I can and credit you in the fix if you wish.
